# Grazioso Salvare Animal Shelter Dashboard

Original project from CS 340: Advanced Programming Concepts at Southern New Hampshire University. This version is the starting point for my CS 499 Capstone database enhancement.

## Overview

A Python dashboard that helps Grazioso Salvare find shelter dogs suited for search-and-rescue training. It reads Austin Animal Center outcome data from MongoDB and displays it with interactive filters, a data table, a breed distribution chart, and a location map.

- **CRUD_Python_Module.py**: an `AnimalShelter` class that wraps PyMongo for create, read, update, and delete operations.
- **ProjectTwoDashboard.ipynb**: a Dash dashboard with Water, Mountain, and Disaster rescue filters.
- **aac_shelter_outcomes.csv**: the dataset (about 10,000 records).

## Requirements

- Python 3.10 or later
- MongoDB Community Server running on `localhost:27017`
- MongoDB Compass (or the MongoDB Database Tools for `mongoimport`)

## Setup

### 1. Create a virtual environment and install packages

```
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. Import the data

Create a database named `aac` with a collection named `animals`, then import `aac_shelter_outcomes.csv`.

**Using Compass:** open the `animals` collection, choose **Add Data > Import JSON or CSV file**, and select the CSV. Make sure `age_upon_outcome_in_weeks`, `location_lat`, and `location_long` are set to **Double**.

**Using the command line:**

```
mongoimport --db aac --collection animals --type csv --headerline --file aac_shelter_outcomes.csv
```

### 3. Create the database user

In `mongosh` (or the MongoDB shell in Compass):

```
use admin
db.createUser({ user: "aacuser", pwd: "yourPassword", roles: [ { role: "readWrite", db: "aac" } ] })
```

### 4. Set credentials and run

Credentials are read from environment variables, so they are never stored in the code.

```
$env:AAC_USER = "aacuser"
$env:AAC_PASS = "yourPassword"
jupyter notebook ProjectTwoDashboard.ipynb
```

Run the cell, then open the link it prints (usually `http://127.0.0.1:8050/`).

## Running outside Codio

This project was originally built in Codio. When running locally, Make sure this line is commented out near the top of the notebook, since it only applies to Codio's proxy:

```
# JupyterDash.infer_jupyter_proxy_config()
```

## Known limitations

These are planned for the CS 499 enhancement:

- `jupyter_dash` is deprecated and requires Dash 2.x.
- No indexes on the fields used by the rescue filters.
- `delete()` and `update()` accept an empty query, which affects every document.
- Record numbers are generated by sorting the whole collection on every insert.
- Rescue filter criteria are hard-coded in Python.
